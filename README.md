# IG-Threads-HD-Saver

IG & Threads HD Saver processes media information from the Instagram or Threads page you’re viewing to provide downloads and conversions. Your language preference is stored locally, and temporary conversion details are kept in Chrome session storage. The extension does not send this information to the developer or use analytics. See the [Privacy Policy](./privacy-policy.md) for details.
