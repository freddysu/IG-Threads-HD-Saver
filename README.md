# IG Threads HD Saver

IG & Threads HD Saver is a Chrome/Firefox extension that processes media information from the Instagram or Threads page you’re viewing to provide downloads and conversions. Your language preference is stored locally, and temporary conversion details are kept in Chrome session storage. The extension does not send this information to the developer or use analytics. See the [Privacy Policy](./privacy-policy.md) for details.

Available on both Firebox and Chrome:
- [IG Threads HD Saver - Chrome](YOUR_CHROME_WEB_STORE_URL)
- [IG Threads HD Saver - Firefox](https://addons.mozilla.org/en-US/firefox/addon/ig-threads-hd-saver/)

Or search "IG Threads HD Saver" in [Chrome Web Store](https://chromewebstore.google.com/) and [Firefox add-ons](https://addons.mozilla.org/en-US/firefox/extensions/)
